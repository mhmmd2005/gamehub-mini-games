# GameHub — Mini Game Arena

یک مجموعه بازی وب فارسی و واکنش‌گرا با چهار بازی مستقل در یک رابط واحد.

## بازی‌ها

- **دوز (Tic-Tac-Toe):** دونفره یا مقابل هوش مصنوعی با سه درجه سختی؛ سطح حرفه‌ای از Minimax استفاده می‌کند.
- **سنگ، کاغذ، قیچی:** فقط مقابل هوش مصنوعی، با سه سطح آسان، متوسط و هوشمند که از تاریخچه انتخاب‌ها برای پیش‌بینی استفاده می‌کند.
- **مار نئونی (Snake):** حرکت با کلیدهای جهت‌دار یا WASD، کنترل لمسی موبایل، افزایش تدریجی سرعت، برخورد با دیوار و دم، امتیاز و رکورد.
- **آجرشکن نئونی (Brick Breaker):** کنترل با موس، لمس یا کلیدهای چپ و راست؛ برخورد توپ و آجر، جان، مراحل افزایشی، افکت ذرات و امتیاز.

## ویژگی‌های مشترک

- رابط فارسی و راست‌چین، واکنش‌گرا و سازگار با موبایل و دسکتاپ.
- طراحی تیره با افکت‌های نئونی و انیمیشن Canvas.
- افکت صوتی اختیاری با Web Audio؛ صدا پس از تعامل کاربر فعال می‌شود.
- امتیازهای دوز و سنگ‌کاغذ‌قیچی و رکورد بازی‌های آرکید با `localStorage` در همان مرورگر ذخیره می‌شوند.
- بدون بک‌اند، دیتابیس، فریم‌ورک یا وابستگی npm؛ مناسب GitHub Pages / Cloudflare Pages.

## ساختار پروژه

```text
 game-hub-cloudflare/
 ├── index.html
 ├── styles.css
 ├── app.js
 ├── README.md
 └── .gitignore
```

## اجرای محلی در Linux Mint

در ریشه پروژه اجرا کن:

```bash
python3 -m http.server 8000
```

سپس آدرس `http://localhost:8000` را در مرورگر باز کن. برای توقف وب‌سرور `Ctrl+C` بزن.

## انتشار روی Cloudflare Pages از GitHub

این پروژه Static HTML/CSS/JavaScript است و به Build واقعی نیاز ندارد.

- **Production branch:** `main`
- **Framework preset:** `None`
- **Build command:** `exit 0`
- **Build output directory:** `.` (ریشه مخزن)

فایل `index.html` باید مستقیماً در ریشه Repository باشد. پس از اتصال Git Integration، Push به شاخه `main` به‌صورت خودکار Deploy جدید ایجاد می‌کند.

## به‌روزرسانی نسخه منتشرشده

پس از جایگزین‌کردن فایل‌ها در مخزن محلی:

```bash
git add index.html styles.css app.js README.md
git commit -m "Add Snake and Brick Breaker arcade games"
git push origin main
```

## محدودیت ذخیره‌سازی

رکوردها و امتیازها در حافظه محلی مرورگر (`localStorage`) ذخیره می‌شوند؛ بین دستگاه‌ها یا مرورگرهای مختلف همگام نیستند. برای حساب کاربری، جدول رتبه‌بندی سراسری یا ذخیره ابری، در آینده باید بک‌اند/API اضافه شود.
