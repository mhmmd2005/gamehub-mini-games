# GameHub — دوز و سنگ، کاغذ، قیچی

یک بازی وب فارسی و واکنش‌گرا که دو بازی را در یک صفحه ارائه می‌کند:

- **دوز (Tic-Tac-Toe):** بازی دونفره یا مقابل هوش مصنوعی با سه درجه سختی؛ سطح حرفه‌ای از Minimax استفاده می‌کند.
- **سنگ، کاغذ، قیچی:** فقط مقابل هوش مصنوعی، با سه سطح آسان، متوسط و هوشمند. دو سطح بالاتر از تاریخچه انتخاب‌های بازیکن برای حدس الگو استفاده می‌کنند.
- امتیازها با `localStorage` در مرورگر نگه داشته می‌شوند.
- رابط فارسی و راست‌چین، واکنش‌گرا و بدون نیاز به بک‌اند یا نصب پکیج است.

## اجرای محلی

فقط فایل `index.html` را در مرورگر باز کنید. برای تست با وب‌سرور محلی (اختیاری):

```bash
python3 -m http.server 8000
```

سپس به `http://localhost:8000` بروید.

## انتشار با GitHub و Cloudflare Pages

1. یک repository جدید در GitHub بسازید.
2. این پوشه را به repository متصل و push کنید.
3. در Cloudflare وارد **Workers & Pages** شوید و **Create application → Pages → Connect to Git** را انتخاب کنید.
4. repository ساخته‌شده را انتخاب کنید.
5. تنظیمات Build:
   - Production branch: `main`
   - Build command: `exit 0`
   - Build output directory: پوشه‌ای که `index.html` در آن قرار دارد؛ در این پروژه ریشه repository است (در داشبورد معمولاً `/` نمایش داده می‌شود).
6. روی **Save and Deploy** بزنید.

فایل `index.html` باید در ریشه repository بماند تا صفحه اصلی روی دامنه `*.pages.dev` نمایش داده شود.

پس از اتصال GitHub، pushهای بعدی به شاخه production به‌صورت خودکار deploy می‌شوند.

## نکته فنی

این نسخه یک سایت استاتیک است. کد Tkinter قبلی یک برنامه دسکتاپ است و در Cloudflare Pages اجرا نمی‌شود؛ این پروژه نسخه وب همان ایده با رابط مرورگر است. امتیازها بین دستگاه‌ها همگام نمی‌شوند، چون بک‌اند و دیتابیس ندارد.
